# Using SKT-T

1. Read `DESIGN.md` before generating an artifact.
2. Import `tokens.css` into the artifact or map its values to the host framework.
3. Use Pretend or Pretendard first, with Apple SD Gothic Neo / Roboto / Noto Sans KR fallbacks.
4. Use T purple for primary actions, active navigation, key badges, and emphasis states only.
5. Keep layouts structured around navigation, summary cards, quick actions, and support shortcuts.
6. Make charges, usage, status, and service eligibility easy to scan before adding decoration.
7. Avoid trendy gradients, oversized marketing cards, or dark enterprise styling that breaks the T world utility tone.
