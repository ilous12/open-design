# Using AIR

1. Read `DESIGN.md` before generating an artifact.
2. Import `tokens.css` into the artifact or map its values to the host framework.
3. Use Pretend/Pretendard as the default font stack.
4. Use AIR Blue only for primary actions, selected states, links, and focus rings.
5. Use the soft AIR box surface sparingly as a signature moment, not as every card.
6. Keep service copy concise and readable on mobile.
7. Avoid adding unrelated accent colors or dark dashboard styling.
