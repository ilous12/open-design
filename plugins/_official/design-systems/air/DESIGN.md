# AIR Design System

This official plugin mirrors `design-systems/air/DESIGN.md`.

Use AIR for Korean-first telecom service flows: simple signup, plan browsing, points benefits, app download, customer support, and self-service onboarding.

Core rules:

- Default font: `Pretend`, `Pretendard`, `Pretendard Variable`, `Noto Sans KR`, system sans.
- Primary text: `#0A0F0F`.
- Primary action and selected state: `#2A60F5`.
- Soft surfaces: `#FFFFFF`, `#F7F7F9`, `#EFF5FF`, `#E1EBFF`, `#CEDDFF`.
- Use 16px+ body copy for service explanations.
- Use pill buttons and large rounded AIR box surfaces sparingly as the signature component.
- Keep layouts bright, readable, and mobile-first.
- Avoid orange/brown accents, dense dark dashboards, and decorative effects that reduce readability.
